RANDOM GRAPH GENERATOR

Це програмне забезпечення призначене для генерації, візуалізації та розрахунку метрик випадкових графів. Проект реалізовано мовою Python з використанням бібліотек NetworkX для математичних розрахунків, FreeSimpleGUI для графічного інтерфейсу та Matplotlib для візуалізації мереж.

Програма дозволяє створювати графи на основі чотирьох моделей: Ердоша-Реньї, конфігураційної моделі, моделі Барабаші-Альберта та моделі тісного світу (Watts-Strogatz). Користувач має можливість налаштовувати кількість вершин, ймовірність з'єднання, кількість сусідів, орієнтованість графа та діапазон ваги ребер. Після генерації система автоматично розраховує ключові метрики, такі як середній коефіцієнт кластеризації (ACC), середня зв'язність вузлів (ANC) та середня довжина найкоротшого шляху (APL).

Функціонал включає систему збереження історії, яка записує параметри створених графів у JSON-файл у робочій папці. Користувач може експортувати структуру графа у текстовий файл, зберігати метрики у форматі CSV, а також завантажувати раніше створені графи з історії для повторного перегляду або видаляти їх.

Для коректної роботи необхідно встановити Python 3 та бібліотеки networkx, FreeSimpleGUI і matplotlib. Запуск програми здійснюється шляхом виконання файлу GUI.py.
